# Lanzou Telegram Bot

A Telegram bot for working with Lanzou cloud-storage links. It is intended to simplify link handling and sharing through Telegram.

## Usage

1. Install the dependencies described by the project.
2. Configure the Telegram bot token and Lanzou settings in the environment file.
3. Start the bot and send it a supported Lanzou link.
4. Follow the bot's replies to retrieve or process the link.

Keep tokens private and test with a non-critical account first.
